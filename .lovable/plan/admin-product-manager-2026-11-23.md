# Admin product manager

## What you will get
- A private admin sign-in page using email and password, with no public admin registration.
- One admin-only product dashboard to add, edit and delete products, including prices, stock, sizes, features and product photos.
- Products saved in Lovable Cloud so changes appear on the storefront for every visitor.
- The existing sample products moved into the database and still clearly labelled as samples.

## Technical setup
- Create product storage, public read access for storefront products and admin-only write permissions.
- Add a separate admin role check; never trust a browser-only admin flag.
- Add protected product save/delete server functions and authenticated image uploads.
- Replace the static product list with a shared product provider so home, shop, search, product, cart and wishlist use saved products.
- Test admin permissions and product validation, then exercise sign-in and product creation in the preview.

## Waiting on you
- Your chosen admin email is needed before creating the single admin account.
- Login only is assumed unless you ask for extra admin profile details.
